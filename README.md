# Htet Aung Shinn — AI & Data Portfolio

## How to use
1. Open `index.html` in a browser to preview the portfolio.
2. Replace the LinkedIn and GitHub placeholder links.
3. Replace `YOUR_EMAIL@example.com` with your real email.
4. Add your exact education details.
5. Replace the placeholder projects with your actual GitHub projects.

## Important
Do not publish confidential company information, internal IP addresses, server serial numbers,
customer information, proprietary scripts, screenshots, or internal procedures from your workplace.
